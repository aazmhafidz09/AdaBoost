AdaBoost Quiz
Playground

Selesaikan algoritma AdaBoost 3 iterasi dengan dataset kelayakan kredit. Isi setiap jawaban dan cek hasilnya secara langsung.

Deskripsi Soal

Suatu algoritma AdaBoost yang terdiri dari 3 weak model dikembangkan secara sekuensial menggunakan dataset yang terdiri dari 9 data point nasabah bank. Setiap data memiliki fitur: Status Pekerjaan, Kepemilikan Rumah, dan Pendapatan (juta/bulan) dengan label target Layak Kredit (Ya = +1, Tidak = −1).


Selesaikan algoritma boosting menggunakan metode AdaBoost untuk: (a) menghitung weighted error dan bobot setiap weak model, (b) update bobot setiap data point setelah tiap iterasi, dan (c) prediksi kelas akhir setiap data.
